# West Michigan park-by-park research (2026-11-12)

Research for Kent, Ionia, Montcalm, Barry, Ottawa, Allegan, Muskegon and Newaygo counties. **Not yet applied to the map.**

- `parks.json` — every park feature in the eight counties from PAD-US and the DNR park layer (807), with the colour the map showed when pulled.
- `parks_*.txt` — the same list grouped by managing body, as given to the researchers.
- `findings_*.json` — one record per managing body (about 180): hunting status, the rule in plain language, the quoted clause, park-specific exceptions, sources and confidence.

About 67 managing bodies have a finding; about 113 are unknown, mostly because the ordinance hosting sites (Municode, eCode360, American Legal) refuse automated requests. A few records in `parks.json` are filed under the wrong county in the source data.
